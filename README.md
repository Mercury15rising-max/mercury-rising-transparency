## Key disclosures

- **Approximately 202,530,000 MERC** is described as team-controlled.
- **100,000,000 MERC** of that stated allocation is designated for community giveaways, contests, and gaming prizes. This is a subset, **not an additional allocation**.
- Designation does **not** mean tokens are locked, transferred, distributed, or independently verified.
- Treasury wallet addresses, balances, supply metrics, and transaction references remain **pending public verification** unless linked to supporting on-chain evidence.

## How to verify

1. Open a disclosure document above.
2. Check whether a claim is labeled project-stated, pending, or independently verifiable.
3. When a public contract address, wallet address, or transaction signature is published, verify it using the relevant blockchain explorer.
4. Review the [changelog](TRANSPARENCY_CHANGELOG.md) and Git commit history for corrections and updates.

**Never share seed phrases, private keys, recovery information, or API credentials.** Public addresses alone do not establish wallet ownership or custody.
