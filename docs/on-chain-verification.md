## Verification checklist

- [ ] Confirm official token mint with project owner and trusted official project channels
- [ ] Confirm which public wallets serve treasury, community rewards, and other functions
- [ ] Record mint decimals, current supply, and relevant mint/freeze authority status from chain data
- [ ] Record dated token balances and supporting explorer links for each disclosed wallet
- [ ] Document distributions with transaction signatures, dates, and amounts
- [ ] Reconcile on-chain evidence with stated tokenomics and disclose any discrepancies
- [ ] Document proof of wallet control using a safe, independently verifiable method

## Safety

Never publish seed phrases, private keys, recovery codes, API credentials, or other secrets. Public verification must rely on public addresses, explorer records, and safe proofs of control.

*This is a preliminary verification checklist, not an audit or proof of reserves.*
