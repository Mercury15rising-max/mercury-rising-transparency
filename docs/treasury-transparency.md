# MERC Treasury Transparency

## Purpose
This document defines how Mercury Rising intends to disclose and verify treasury activity.

## Wallet separation
The project uses a separate treasury wallet. A wallet being described as a treasury wallet does not independently establish custody, balances, or security guarantees.

## Controls and safety
Only publish verified public wallet addresses and on-chain transaction links. Never publish seed phrases, private keys, signing credentials, recovery information, or confidential infrastructure settings. Record corrections openly and preserve historical entries.

## Verification limits
These disclosures are project-maintained records, not an audit or proof of reserves until verifiable evidence is provided.
